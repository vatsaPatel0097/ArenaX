# ArenaX Backend

FastAPI asynchronous backend for ArenaX - Open-Source LLM Battleground & Evaluation Platform.

## Requirements
- Python 3.11+
- PostgreSQL
- Redis

## Development Setup

```bash
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -e .[dev]
```

## Running Tests

```bash
pytest
```
